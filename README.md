# Cyber_Forensics_Portfolio
 I build a HTML web browser based Digital Forensics and Investigation Methods, practical forensic capability across the full evidence lifecycle — acquisition, analysis, and courtroom presentation.in accordance NIST Cybersecurity Framework (CSF).
My capstone work covers forensic disk imaging with verified integrity (FTK Imager), reconstruction of a multi-stage network intrusion from raw packet captures (Wireshark), and legal analysis of digital evidence admissibility under Nigeria's Evidence Act 2011, including the Supreme Court's landmark decision in <em>Kubor v. Dickson</em>.
